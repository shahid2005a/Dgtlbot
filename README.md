📦 Installation Guide

🔥 One-Click Installation

```bash
pkg update && pkg upgrade -y
pkg install python -y
pip install pyTelegramBotAPI 
pkg install nano
pkg install git
git clone https://github.com/shahid2005a/Dgtlbot.git
cd Dgtlbot
nano PythonBot.py
python PythonBot.py
```
